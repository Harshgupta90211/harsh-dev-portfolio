## About the Project

Welcome to my personal developer portfolio! This website showcases my technical skills, projects, academic background, and journey as a Computer Science Engineering student aspiring to become a software engineer.

The portfolio is designed with a modern developer-focused interface to present my work, demonstrate my frontend development skills, and provide an easy way for recruiters and fellow developers to connect with me.

## ✨ Features

- **Personal Introduction** — An overview of my background and career goals.
- **About Me** — My academic journey and interest in software engineering.
- **Skills Showcase** — Technologies and programming concepts I am learning.
- **Projects Section** — A collection of my development projects.

## 💻 Run Locally

You can run this project on your computer by following these steps.

**1. Clone the repository**

```bash
git clone https://github.com/Harshgupta90211/harsh-dev-portfolio.git
```

**2. Navigate to the project directory**

```bash
cd harsh-dev-portfolio
```

**3. Open the website**

Open `index.html` in your browser, or open the project in Visual Studio Code and use the Live Server extension.
